### 进制转换

[![[2c2a5a6ff34d6840c2d26eeb5bb2762f.jpg]]](https://github.com/Cloverine-Hou/Computer-Science-and-Technology-2604/blob/main/Notes/Image/2c2a5a6ff34d6840c2d26eeb5bb2762f.jpg)

核心方法：

- **转十进制**：按权展开相加  
- **转八进制**：从小数点向两边，每 **3 位**一组  
- **转十六进制**：从小数点向两边，每 **4 位**一组  

---

## 1. 二进制转十进制：按权相加

小数点左边第 1 位是 \(2^0\)，第 2 位是 \(2^1\)，依次增加；  
小数点右边第 1 位是 \(2^{-1}\)，第 2 位是 \(2^{-2}\)，依次减小。

---

## 2. 二进制转八进制：每 3 位一组

以小数点为界：

- 整数部分：从右往左每 3 位一组，不足左边补 0
- 小数部分：从左往右每 3 位一组，不足右边补 0

对应关系：

| 二进制 | 八进制 |
|---|---|
| 000 | 0 |
| 001 | 1 |
| 010 | 2 |
| 011 | 3 |
| 100 | 4 |
| 101 | 5 |
| 110 | 6 |
| 111 | 7 |

---

## 3. 二进制转十六进制：每 4 位一组

同样以小数点为界：

- 整数部分：从右往左每 4 位一组，不足左边补 0
- 小数部分：从左往右每 4 位一组，不足右边补 0

对应关系：

| 二进制 | 十六进制 |
|---|---|
| 0000 | 0 |
| 0001 | 1 |
| 0010 | 2 |
| 0011 | 3 |
| 0100 | 4 |
| 0101 | 5 |
| 0110 | 6 |
| 0111 | 7 |
| 1000 | 8 |
| 1001 | 9 |
| 1010 | A |
| 1011 | B |
| 1100 | C |
| 1101 | D |
| 1110 | E |
| 1111 | F |

---

## 总结

二进制转其他进制：

1. **转十进制**：每位乘对应权值，再相加。
2. **转八进制**：每 3 位二进制变 1 位八进制。
3. **转十六进制**：每 4 位二进制变 1 位十六进制。

记忆口诀：

> 十进制按权加，八进制三位一组，十六进制四位一组。
