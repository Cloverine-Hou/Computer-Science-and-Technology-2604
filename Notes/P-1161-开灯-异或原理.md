# 题解：唯一开着的灯（利用异或特性）

## 思路解析

由于最终只有一盏灯是开的，这意味着这盏灯被按了奇数次，而其他所有灯都被按了偶数次。

这里可以利用异或运算的特性：
* 任何数与 0 异或结果是它本身；
* 任何数与自身异或结果是 0。

因此，我们可以将每次操作涉及的灯的编号进行异或运算，最终得到的结果就是唯一开着的灯的编号。

## 原题代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int n, t, ans, x;
double a;
int main() {
    cin>>n;
    for(int i=1; i<=n; i++) {
        cin>>a>>t;
        for(int j=1; j<=t; j++) {
            x=(int)floor(a*j);//a*j为当前灯的编号
            ans^=x;
        }
    }
    cout<<ans;
    return 0;
}
```
# 为什么可以用异或（XOR）？

这个题解的核心原理是**利用异或（XOR）运算的特性来判断奇偶性**。我们可以分步骤来理解：

## 1. 物理现象转换为数学问题：奇偶性

* 路灯初始全关。
* 按 **1 次** -> 开
* 按 **2 次** -> 关
* 按 **3 次** -> 开

可以发现：**被按了奇数次的灯是开的，被按了偶数次的灯是关的。**

题目已知最后**只有一盏灯是开的**，这意味着：在所有的操作中，这盏灯的编号出现了**奇数次**，而其他所有被操作过的灯的编号都出现了**偶数次**。

## 2. 为什么使用异或（XOR）？

异或运算（符号 `^`）有两个关键特性：
* `a ^ a = 0` （任何数和自己异或等于 0）
* `a ^ 0 = a` （任何数和 0 异或等于它本身）
* 并且异或满足**交换律和结合律**。

题解的做法是：**把所有操作中出现的灯的编号全部异或起来**。
* 如果某盏灯被操作了**偶数次**（比如2次），它的编号在式子中就会出现两次，根据 `a ^ a = 0`，它就会**抵消**掉。
* 如果某盏灯被操作了**奇数次**（比如1次），它就会留到最后。
* 因为题目保证最后只有**唯一一盏**灯亮着，所以把所有出现过的编号异或在一起，互相抵消后，剩下的那个数字，**必然是那盏唯一亮着的灯的编号**。

## 3. 代码细节对应

```cpp
for(int j=1; j<=t; j++) {
    x = (int)floor(a*j); // 对应题目：计算当前按下的灯编号 |j*a|
    ans ^= x;            // 把该编号累积进行异或
}
```

* `a * j` 是实数，`floor()` 向下取整，完全对应题目公式中的 \(\lfloor j \times a \rfloor\)。
* `ans` 初始为 0（`a ^ 0 = a`，不影响结果），不断把当前操作到的灯编号 `x` 异或进去。

## 4. 举个简单的例子

假设一共只有 3 次按灯操作，编号分别是：`2`, `2`, `3`。
* 编号2被按了两次（偶数次，最终是关的）；
* 编号3被按了一次（奇数次，最终是开的）。

按照题解的代码逻辑，`ans` 的计算过程如下：
1. 初始 `ans = 0`
2. 遇到 2：`ans = 0 ^ 2 = 2`
3. 遇到 2：`ans = 2 ^ 2 = 0` （2 被抵消了）
4. 遇到 3：`ans = 0 ^ 3 = 3`

最终输出 `3`，完美找出唯一开着的灯。

## 5. 算法的优势

不需要开一个巨大的数组去记录每一个灯的状态（因为灯的编号可能很大），只需要一次遍历。

* **时间复杂度**：\(O(总操作次数)\)，极其高效。
* **空间复杂度**：\(O(1)\)，只用了几个变量。
